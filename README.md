## 香港高防服务器到底在防什么

高防的核心不是“有多大的数字”，而是攻击来了以后你的 IP 会不会消失。DDoS 防护一般分三件事：检测异常流量、把攻击流量牵引到清洗设备、把干净流量回注给你。运营商级别的联合清洗能处理到几百 G，成本高；机房侧的基础清洗只能过滤明显异常包，成本低，通常打包进服务器价格。

真正决定业务能不能撑住的，是清洗之外的那条兜底规则——黑洞。当攻击量超过清洗能力，机房的标准动作是把你的 IP 直接封掉一段时间，攻击停了再解封。这段时间业务是彻底断的，不是变慢。

这个逻辑对选商家很实用：如果你被攻击的概率高、而且攻击一旦发生就完全不能断，那你需要的是一份写明清洗峰值和黑洞触发条件的付费防护，而不是一个“最高支持 600G”的宣传语。
